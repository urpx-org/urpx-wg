# URPX Working Group

Public materials of the **URPX (Utility Rate Plan Exchange) Working Group**, hosted under **LF Energy Standards and Specifications (LFESS)**, a Linux Foundation project.

URPX is an open standard for exchanging utility rate plan information using semantic web technologies (RDF, OWL, SHACL). The standard itself is developed in the [urpx repository](https://github.com/urpx-org/urpx).

## What is here

| Directory | Contents |
|-----------|----------|

## Participating

- **Mailing list:** [urpx-wg@lists.lfenergy.org](https://lists.lfenergy.org/g/urpx-wg) — meeting invitations and working group discussion.
- **Meetings** are open to all participants. Notes are published here; recordings are available to attendees through the meeting platform.

## Governance

The working group operates under its LFESS charter, which designates it as the body responsible for promoting URPX materials through the LFESS stages (Sandbox → Draft → Approved). Roles and decision making are described in the [urpx repository's GOVERNANCE.md](https://github.com/urpx-org/urpx/blob/main/GOVERNANCE.md).
